# HK Market Breadth: 2800.HK 多週期與板塊寬度 [v6.2]

這是一個專為 **香港股市（盈富基金 2800.HK / 恒生指數核心 36 隻成分股）** 設計的 TradingView Pine Script v6 市場寬度（Market Breadth）指標。

🌐 **專案網站與一鍵複製**：`https://<你的GitHub帳號>.github.io/hk-market-breadth-2800/`

## 核心功能
- **雙顯示模式**：
  - **模式 A（整體寬度）**：同時追蹤 20 / 50 / 200 SMA 的成分股站上比例。
  - **模式 B（板塊輪動）**：拆解「整體恒指」、「恒生科技核心」、「金融與地產」、「消費與公用」4 大曲線。
- **全景矩陣 Dashboard**：右上角即時顯示各板塊多週期數值、歷史回溯變化（預設 5 日前對比）與結構狀態。
- **6 大內建警報條件**：支援黃金/死亡交叉、20% 超賣反彈、80% 超買回落、50% 多空分水嶺突破與跌破。

## 追蹤成分股（共 36 隻）
- **科技與新經濟 (10 隻)**：700, 9988, 3690, 1810, 9618, 9999, 9888, 1024, 981, 992
- **金融與地產 (14 隻)**：5, 1299, 939, 388, 1398, 3988, 2318, 3968, 2628, 2388, 16, 1113, 823, 688
- **消費、公用與能源電訊 (12 隻)**：1211, 941, 883, 857, 1, 2, 669, 2020, 9633, 27, 1093, 175

## 使用方法
1. 複製 `hk_market_breadth_v6.2.pine` 內的程式碼。
2. 開啟 [TradingView](https://www.tradingview.com/)，切換至日線圖（建議標的：`HKEX:2800` 或 `HSI`）。
3. 開啟底部 **Pine Editor**，貼上程式碼並點擊 **Add to chart**。
